Responsive CSS Cheat Sheet

Filters

Apply visual effects such as blur or grayscale.

img { filter: grayscale(100%); }

Media Queries

Apply styles only when a screen condition is true.

@media (max-width: 700px) { ... }

Responsive Design

Layouts that adapt to any screen size.

repeat(auto-fit, minmax(200px, 1fr))

Typography

Text that scales with the viewport.

font-size: clamp(1rem, 2vw, 1.5rem);

Flexbox

One-dimensional layout for rows or columns.

display: flex; gap: 20px;

Transitions

Animate a property change smoothly.

transition: transform 0.3s ease;
